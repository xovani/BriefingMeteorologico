# Contribuir

Use Python 3.11 ou superior e um ambiente virtual. Instale requirements.txt e execute python -m pytest antes de propor alteracoes.

Mantenha interface e relatorios em portugues. Preserve separacao entre GUI, APIs, modelos, analise e relatorios. Testes unitarios nao devem depender da internet.

Consulte a documentacao oficial antes de alterar endpoints. Nunca invente dados ausentes nem apresente uma inferencia como alerta oficial. Preserve os avisos de uso educacional.

Ao abrir uma issue, descreva o problema, a versao do Windows/Python ou do EXE e passos de reproducao. Remova dados pessoais dos logs compartilhados.
